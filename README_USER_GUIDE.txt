Excel工作簿拆分器 1.0.0

用途：
把一个 Excel 工作簿中的多个工作表，分别保存为多个独立 Excel 文件。

使用方法：
1. 双击运行 ExcelWorkbookSplitter.exe。
2. 点击“浏览”，选择需要拆分的工作簿。
3. 勾选需要导出的工作表。
4. 选择保存位置。
5. 点击“开始拆分”。

支持格式：
.xlsx、.xlsm、.xltx、.xltm

注意事项：
1. 拆分前请关闭正在占用源文件的 Excel 窗口。
2. 不支持旧版 .xls 文件，请先在 Excel 中另存为 .xlsx。
3. 输出文件重名时，软件会自动添加编号，不会直接覆盖。
4. 软件不联网，不上传工作簿，全部处理均在本机完成。
